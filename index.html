How to install on Firefox

  1. Download the add-on(s) you want above.
  2. Extract the ZIP — you will see manifest.json inside.
  3. Open Firefox → about:debugging → This Firefox → Load Temporary Add-on…
  4. Select manifest.json. Repeat for each add-on you downloaded.
  5. The icons appear in your toolbar — click any of them to use it.

Extensions loaded via about:debugging are temporary and disappear when Firefox closes. For permanent installation, the add-on must be signed by Mozilla — submit it for free as an unlisted (self-distributed) add-on at addons.mozilla.org/developers and install the signed .xpi.
