How to install on Firefox

  1. Click Download ZIP above.
  2. Extract the ZIP — you will see manifest.json inside.
  3. Open Firefox and go to about:debugging in the address bar.
  4. Click This Firefox → Load Temporary Add-on…
  5. Select manifest.json from the extracted folder.
  6. The bee 🐝 appears in your toolbar. Click it to open all tools.

Tutorial — managing & keeping the extension

1. Temporary vs. permanent installation

Extensions loaded via about:debugging are temporary: they disappear when you close Firefox. For a permanent install, the add-on must be signed by Mozilla. You can submit it for free as an unlisted (self-distributed) add-on at addons.mozilla.org/developers, then install the signed .xpi file permanently.

2. Keyboard shortcuts

  • Ctrl+Shift+D — toggle draw mode on the active tab
  • Ctrl+Shift+U — open the panel (if configured)

3. Kuda AI Ask! setup

  1. Create a free API key at openrouter.ai/keys.
  2. Click the bee 🐝 in the toolbar → scroll to Kuda AI Ask!
  3. Paste your key, pick a model (e.g. openai/gpt-4o-mini), click Simpan Pengaturan.
  4. Start chatting — your key never leaves your device except to OpenRouter.

4. Troubleshooting

  • Nothing happens when drawing? Internal pages (about:*, addons.mozilla.org) block extensions for security — try a normal website.
  • Camelo shows 0? Reload the page after installing; counters only see requests made after the extension loaded.
  • APK Guard blocking too much? Toggle it off in the panel; it applies to pages loaded afterwards.

FAQ

Is it really free? Yes. Open source, no accounts, no payments.

Does it steal my data? No. Notes, API keys and scores are stored locally via Firefox's storage.local. The IP lookup uses Cloudflare DoH; Kuda AI uses your own OpenRouter key.

Chrome/Edge? This build targets Firefox (Manifest V2). A Chrome port would need a Manifest V3 rewrite.
