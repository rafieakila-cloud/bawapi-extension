Cara Install di Firefox

  1. Unduh ZIP extension yang kamu mau.
  2. Ekstrak — akan ada file manifest.json.
  3. Buka Firefox, ketik about:debugging di address bar.
  4. Klik This Firefox → Load Temporary Add-on…
  5. Pilih file manifest.json dari folder hasil ekstrak.

Extension sementara hilang saat Firefox ditutup. Untuk permanen, extension harus ditandatangani Mozilla — daftar gratis sebagai unlisted di addons.mozilla.org/developers.
